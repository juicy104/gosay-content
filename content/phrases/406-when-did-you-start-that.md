## すぐ使う

`When did you start that?` は、相手の趣味・仕事・活動について、いつ始めたのか聞く場面に使います。

相手に話してもらいながら、英語の会話を自然に続けるための表現です。

## かたまり・型

これは、まず丸ごと覚える固定フレーズです。

`When did you start that?` をひとまとまりで入れておくと、雑談やオンライン英会話で会話を続けやすくなります。

## 実用メモ

会話を続けたいときは、自分が長く話すより、相手に話してもらう質問を出せる方が楽です。

まずはこの一文をそのまま使えるようにしておくと便利です。
