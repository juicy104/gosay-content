## すぐ使う

`I'll get started on it.` は、「それに取り掛かります」と伝えたいときに使います。

仕事で依頼された作業やタスクに、これから着手すると伝える場面で便利な一文です。

チャットや会議で、

`I'll get started on it.`

と言えば、「それに取り掛かります」「これから始めます」という意味になります。

## かたまり・型

これは、まず丸ごと覚える固定フレーズです。

`I'll get started on it.`

をひとまとまりで入れておくと、仕事の依頼に対してすぐ返しやすくなります。

`I'll` は `I will` の短い形です。

`get started on ...` は「〜に取り掛かる」「〜を始める」という意味です。

`it` は、相手が依頼した作業や今話しているタスクを指します。

全体で、

「それに取り掛かります」
「その作業を始めます」
「これから着手します」

という意味になります。

## get started on の意味

`get started on ...` は、「〜に取り掛かる」という意味で使えます。

単に `start` と言うよりも、仕事やタスクに着手する感じが出ます。

そのため、作業依頼を受けたあとに、

`I'll get started on it.`

と言うと、自然に「それに取り掛かります」と伝えられます。

## start it との違い

`I'll start it.` でも意味は伝わります。

ただし、少し短く、やや機械的に聞こえることがあります。

`I'll get started on it.` は、仕事のやり取りで自然に使いやすい表現です。

「今から作業に入ります」「着手します」という感じが出るので、仕事チャットにも向いています。

## it の意味

`it` は、相手が依頼した作業や、今話しているタスクを受けています。

たとえば、相手が

`Could you check this file?`

と言ったあとに、

`I'll get started on it.`

と返せます。

この場合の `it` は「そのファイル確認の作業」を指します。

## 実用メモ

仕事では、依頼を受けたあとに何も返さないと、相手は着手するのか不安になることがあります。

そのときに、

`I'll get started on it.`

と返せると、作業に入る意思がはっきり伝わります。

必要なら、

`I'll get started on it today.`

のように、いつ始めるかを足すこともできます。

## まずは増やしすぎない

この意味では、最初から細かく進め方まで説明しなくても大丈夫です。

まずは、

`I'll get started on it.`

を「それに取り掛かります」の一文として反射で出せるようにします。

短く、自然で、仕事の依頼に返しやすい表現です。
