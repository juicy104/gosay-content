## すぐ使う

`Another task came up, so I couldn't work on it.` は、別のタスクが差し込まれて、予定していた作業を進められなかった場面に使います。

英語ミーティングや仕事の短いやり取りで、状況や意図を短く伝えるための表現です。

## かたまり・型

これは、まず丸ごと覚える固定フレーズです。

`Another task came up, so I couldn't work on it.` をひとまとまりで入れておくと、仕事の会話やミーティング中にすぐ使いやすくなります。

## 実用メモ

仕事の英語では、長く説明するより短く状況を共有できることが大事です。

まずはこの一文をそのまま使えるようにしておくと便利です。
