## すぐ使う

`I think so too.` は、「私もそう思います」と同意したいときに使います。

相手の意見や考えに対して、自分も同じように思っていると伝える一文です。

雑談や英語ミーティングで、相手の意見を聞いたあとに、

`I think so too.`

と言えば、「私もそう思います」「私も同じ意見です」という意味になります。

## かたまり・型

これは、まず丸ごと覚える固定フレーズです。

`I think so too.`

をひとまとまりで入れておくと、相手の意見にすぐ同意しやすくなります。

`I think so` は「そう思います」です。

`too` は「私も」という意味です。

全体で、

「私もそう思います」
「私も同じように思います」
「私もその意見です」

という意味になります。

## Me too との違い

`Me too.` も「私も」という意味で使えます。

ただし、`Me too.` は何に同意しているのかが少し曖昧になることがあります。

たとえば、相手が自分の経験や状態を話したときは、

`Me too.`

で自然です。

一方で、相手の意見に対して「私もそう思います」と言いたいなら、

`I think so too.`

の方が合います。

意見への同意をはっきり伝えられるからです。

## I agree との違い

`I agree.` も「同意します」という意味で自然です。

ただし、少しはっきりした同意で、会議や議論っぽい響きがあります。

`I think so too.` は、もう少し会話寄りでやわらかいです。

雑談やオンライン英会話で、相手の考えに自然に乗るなら、

`I think so too.`

が使いやすいです。

## 実用メモ

相手が意見を言ったあとに、何も返せないと会話が止まりやすくなります。

そのときに、

`I think so too.`

と言えると、自分も同じ意見だと短く返せます。

たとえば、相手が

`English is difficult, but it's useful.`

と言ったら、

`I think so too.`

と返せます。

## まずは増やしすぎない

この意味では、最初から `I agree.`、`Me too.`、`Exactly.` まで細かく使い分けなくても大丈夫です。

まずは、

`I think so too.`

を「私もそう思います」の一文として反射で出せるようにします。

短く、自然で、相手の意見に同意しやすい表現です。
